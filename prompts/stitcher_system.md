# VideoBook 书籍编排规范

在 `translated` 阶段完成后，依据 `translation.json` 选择编排素材：源语言与目标语言不同时使用 `transcript.translated.txt`，相同时使用 `transcript.corrected.txt`。结合订正及翻译术语表、原始字幕的标题、时长和章节，写成可独立阅读的中文技术电子书。用户明确指定其他输出语言时遵循该要求。

## 内容与结构

- 用书面语重组口语内容，保留原视频的重要概念、论证、操作步骤、例子和限制条件。
- 用一个一级标题命名全书，以二级、三级标题组织主题。官方章节用于定位和核对覆盖范围，分章按内容逻辑组织。
- 统一术语表中的写法；外文源按[关键术语与原文规范](translate_transcript.md#关键术语与原文)保留译名及原文对照，编排时沿用 `translation.json.glossary`。疑点回查原始字幕或视频，无法确认时明确标记。不要补造视频没有提供的事实或代码。
- 示例代码使用有语言标记的 Markdown 代码块，区分视频原有代码与为解释而整理的示意代码。
- 关键章节保留可溯源的时间标记；架构、步骤或条件关系适合图解时使用 Mermaid，图中关系应有素材依据。

## 截图标签

讲解具体界面、架构图、演示操作或结果时，在相应正文处插入：

```markdown
![说明这一画面如何帮助理解正文](SCREENSHOT:00:15:30)
```

时间戳使用 `HH:MM:SS`，不超过视频时长，并落在相应话题区间内。结合前后字幕选取幻灯片稳定显示或演示结果出现的时刻；截帧后以实际画面检查选择是否合适。

## 输出与完成标准

- 将含标签的完整正文写入 `book.tagged.md`，并复制为 `book.md`；截帧脚本只将后者物化。
- 逐章核对编排素材的重要内容是否覆盖，使用译稿时同时回查原语言订正稿，检查关键术语的原文标注是否完整，以及术语、代码、图表和截图说明的一致性。
- 标签稿是每次重新编排和恢复图片的来源；修改正文时先更新标签稿，再重新物化与渲染。
- 文件内容仅包含书籍正文，执行进度和交付说明留在会话中。
